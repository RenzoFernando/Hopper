<br>

Hopper es una PWA para mover contenido temporalmente entre dispositivos desde un espacio privado protegido por PIN o mediante salas públicas. Permite compartir texto y archivos, recuperar el acceso por correo y recibir contenido desde aplicaciones compatibles con Web Share Target.

## Características

- Transferir texto, código, imágenes, documentos, ZIPs, audio y otros archivos.
- Proteger Mi espacio con un PIN de cuatro dígitos y recuperación por correo.
- Crear hasta tres salas públicas simultáneas con códigos de acceso independientes.
- Mantener las salas activas con la actividad y cerrarlas tras 5 minutos de inactividad.
- Subir archivos con cola, progreso, cancelación y reintentos seguros.
- Previsualizar imágenes y reproducir audio mediante URLs firmadas temporales.
- Instalar Hopper como PWA y recibir contenido mediante Web Share Target.
- Consultar uso, salud, límites, salas y mantenimiento desde Administración.

## Tecnologías

- React + TypeScript
- Vite
- Cloudflare Pages
- Cloudflare Workers
- Cloudflare D1
- Backblaze B2
